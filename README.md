# 📚 Коллекция скриптов-помощников

## 🔧 1. WordPress SimplyStatic Fix
**Файл:** `01_WordPress_SimplyStatic/repair_wordpress_export.py`
**Назначение:** Исправляет некорректные имена файлов после экспорта из плагина SimplyStatic
**Проблема решает:** Преобразует `cataloghallsindex.html` → `catalog/halls/index.html`
**Запуск:** `python repair_wordpress_export.py`

## 🎨 2. 3Ds Max Render Organizer
**Файл:** `02_3DsMax_Render_Organizer/organize_3dsmax_render_layers.py`
**Назначение:** Сортирует файлы рендеров по папкам в зависимости от типа (Direct, Reflect, и т.д.)
**Запуск:** `python organize_3dsmax_render_layers.py` или двойной клик по `.bat`

## 🔗 3. Obsidian Connection Finder
**Файл:** `03_Obsidian_Linker/find_obsidian_connections.py`
**Назначение:** Автоматически находит и добавляет связи между заметками в Obsidian
**Запуск:** `python find_obsidian_connections.py`

## 📄 4. Markdown Analyzer
**Файл:** `04_Custom_Folder_Analyzer/analyze_markdown_connections.py`
**Назначение:** Анализирует markdown-файлы и предлагает связи между ними
**Особенность:** Учитывает теги и заголовки для более точных рекомендаций

## ✨ 5. Telegram Channel Updater ❌
**Папка:** `05_Telegram_Channel_Updater/` (Отсутствует)
**Назначение:** Автоматическое обновление телеграм-канала (Отсутствует)

## 📊 6. Catalog Parser
**Папка:** `06_Parsing_Catalog/`
**Назначение:** Парсинг каталогов товаров/услуг в формате PDF (переводит страницы в изображения).
